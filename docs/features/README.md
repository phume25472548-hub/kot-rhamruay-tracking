# สารบัญฟีเจอร์

อ่านวิธีใช้และแม่แบบที่ `docs/FEATURE_NOTES.md`

| ฟีเจอร์ | คู่มือ | ส่วน | สถานะ | ใช้เมื่อ |
|---|---|---|---|---|
| ติดตามพัสดุ | [tracking-parcel.md](tracking-parcel.md) | `tracking` | ใช้งานได้ | ลูกค้ากรอกเลขพัสดุหนึ่งหรือหลายเลขเพื่อดูสถานะขนส่งจีน-ไทยจาก CNS Cargo |
| ล็อตสินค้า | ยังไม่มีคู่มือ | `lots` | ยังไม่เปิดใช้ | API `/api/lots` คืนข้อมูลตัวอย่างที่เขียนไว้ในโค้ด ยังไม่มีหน้าจอ |
| สั่งงานขนส่ง | ยังไม่มีคู่มือ | `orders` | ยังไม่เปิดใช้ | API `/api/orders` รับออเดอร์เก็บไว้ในหน่วยความจำ ยังไม่มีหน้าจอ |
